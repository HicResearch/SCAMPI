What it does

From DICOM files to data you can work with.

SCAMPI handles the repetitive plumbing between imaging sources, metadata, and your downstream workflows.

01

Connect your source

Read from a local filesystem or query a PACS using DICOM Query/Retrieve. Configure multiple named sources in one run.

02

Extract modality metadata

Use modality-specific .it templates to select the DICOM tags that become structured metadata.

03

Write to SQL Server

Store extracted metadata in your SQL Server database and keep a reference to the processed file location.

04

Keep files organized

Copy source files to your chosen output directory, with optional compression and archive input support.

Quick start

Up and running in three steps.

Configure your source and SQL Server connection, build the image, then mount the paths SCAMPI needs.

Docker SQL Server DICOM source
01

Create your config

Use the Config Wizard to set up your DICOM sources, file output, and database connection, then download your config.yml.

02

Create or download modality metadata template files

SCAMPI comes with some example templates to get you started

03

Run SCAMPI

Mount the config, DICOM source, output directory, and modality templates.

docker run --rm \
  -v /path/to/config.yml:/config.yml \
  -v /path/to/dicoms:/my_images \
  -v /path/to/output:/output \
  -v /path/to/templates:/templates \
  taggenblu/scampi:latest
